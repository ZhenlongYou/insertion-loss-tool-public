# 重合曲线补齐与参数映射规格

## 用户可观察行为

1. 当同一幅图的两条同参数曲线发生一次或多次像素级重合时，数字化结果保留两条曲线，并让两条曲线使用绘图区逐列对应的同一横轴网格。
2. 重合处允许两条曲线引用同一个已观测像素；再次分离后恢复为两条独立轨迹。不能为了等长而把一条曲线整体复制成另一条。
3. 只有夹在两侧真实观测之间的短缺口允许插值；长缺口、边缘缺口或轨迹关系不明确时保持不完整结果，不强行补齐。
4. 每条曲线分别报告总点数、`observed_samples`、`shared_overlap_samples` 与 `interpolated_samples`。共享点和插值点都不提高识别置信度。
5. OCR 或用户确认得到的 `Sij`、`SDDij`、`SDCij`、`SCDij`、`SCCij` 参数，只出现在右侧兼容参数下拉框中；同一参数的多条曲线都可选，但不自动替用户二选一。
6. 图题无法唯一确定参数时，不做自动重合补齐；曲线保持“未分配”，由用户先选择参数。

## 补齐判据

- 受遮挡曲线的可见起点位于绘图区内部，供体曲线覆盖绘图区左边界和受遮挡曲线的可见范围。
- 两条曲线在受遮挡曲线起点附近的位置连续，且之后存在可观测分离，证明它们不是同一条重复检测曲线。
- 只有一个供体满足条件；多供体歧义时不补齐。
- 补齐仅复制供体在可见曲线首点之前的原始采样，不插值生成额外横坐标。

## 重复重合的耦合跟踪判据

- 只对“参数已唯一确定且正好识别出两条曲线”的图片启用，避免把未知数量的轨迹强行解释为两条。
- 每个横向像素列都建立候选观测；动态跟踪可把同一候选同时分配给两条曲线，也可在曲线分离时分配不同候选。
- 原始已跟踪点作为锚点参与校验；新轨迹偏离锚点超过容差时放弃补齐，保留原始识别结果。
- 内部无观测缺口最多允许约绘图区宽度的 `0.8%`（且至少 3 列）；超出该长度或缺少双侧观测时不跨越缺口。
- 输出频率轴仍由用户确认的起点、终点和横轴类型标定；共享网格表示相同横坐标，不代表两条曲线的纵坐标必须相同。

## 验收样例

- 合成 SDD21 图：青色全长，橙色在前段与青色重合、分叉后可见。输出两条等长全范围曲线；橙色共享前缀与青色一致，且共享点数大于零。
- 合成 SCC11 图：两条低饱和度曲线多次重合、分离并具有不同凹口。输出两条等长全范围曲线；重合段计为共享点，分离段保持可测的纵向差异。
- 删除内部 3 列曲线像素时，只补这段短缺口并计为插值点；删除 11 列时不得生成两条伪造的全范围曲线。
- 晚起始但在起点处不与全长曲线连续的曲线不得补齐。
- 对 `S21`、`SDD21`、`SDC21`、`SCD21`、`SCC21` 逐一验证：识别曲线能在对应右侧下拉框中选择，且不会出现在不兼容参数下拉框中。
