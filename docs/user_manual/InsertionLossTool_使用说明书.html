使用说明书

工具版本：0.6.0 识图功能：0.6.0 源码版 文档日期：2026-09-22 平台：Windows / macOS 输出：Touchstone .sNp
1 · PURPOSE

工具用途与结果边界

Insertion Loss Tool 用于生成、修改、查看和保存 Touchstone S 参数文件，也可从曲线图片提取幅度并组合成完整网络。

直接生成按线性插损、公式或手绘控制点建立 2/3/4/6/8 端口 S 参数。
修改现有文件在指定频点把指定 Sij 调整到目标插损，保留原始相位，并输出修改报告。
图片转网络识别曲线图片的频率、幅度和曲线路径，再把各条曲线映射到 Sij 或混合模参数。
结果不是合规证书。程序在每个输出采样频点检查完整 S 矩阵的最大奇异值，保证“采样点无源”。这不证明采样点之间的宽带因果性、稳定性、物理可实现性，也不证明它代表某一条真实线缆、连接器或封装。

图片页只能恢复图中可见的幅度轨迹，无法从一张幅度图恢复原始相位、参考阻抗变换或未画出的矩阵元素。该页输出明确采用零度相位近似。

实现依据：采样点无源诊断；图片网络的幅度、相位与导出合同。

4 · GENERATE & MODIFY

生成页公共参数与四种模式

4.0 Sweep 与公共输出设置

界面项作用默认值 / 输入要求
Ports设置输出网络的物理端口数。默认 2；可选 2、3、4、6、8。Modify 载入文件后由源文件端口数替换。
Points设置 Linear、Formula、Draw 的基础扫频点数。默认 801，必须为有效整数。Draw 会把控制频点额外插入输出网格。
Start / Stop设置生成频率范围。数值必须带 Hz/kHz/MHz/GHz。默认 10 MHz / 40 GHz；Stop 必须大于 Start。Modify 中由输入文件替换。
Output File留空时自动写入默认输出目录；也可输入完整路径。扩展名会按端口数修正为 .sNp。
Browse（Output）打开保存对话框，选择输出位置和文件名。取消对话框不会改变现有路径。
Open Folder打开生成页最近一次成功输出所在目录。本次启动尚未成功生成时提示“尚未生成文件”。
Generate校验当前模式参数，在后台生成、执行完整矩阵无源检查、写文件并刷新曲线。运行时显示 Generating 并禁用；不会同时启动第二个生成任务。

More Parameters 折叠区

点击 More Parameters 标题可展开或收起。不同模式只读取与自己有关的参数；例如 Draw Y Min 不影响 Linear，Modify Curve Tension 不影响 Formula。

参数功能重要边界
Sweep Spacinglinear 等间隔频率；log 等间隔对数频率。改变生成频点分布，不会把右侧显示轴改成对数轴。
Touchstone Format选择 RI、MA 或 DB 数据编码。只改变文件表示方式，不改变内部复数 S 参数。
Frequency Unit选择写入 Touchstone 的频率单位，同时用于曲线横轴和 Draw 坐标标签。与 Formula 自己的 Frequency Unit 是两个不同设置。
Return Loss (dB)为对角反射项设置正数形式的回波损耗。默认 20 dB；数值越大，反射幅度越小。
Crosstalk (dB)为未指定为 through 的非对角项设置串扰底。默认 80 dB；数值越大，串扰幅度越小。
Delay (ps)给生成的 through 路径加入随频率线性变化的延时相位。默认 80 ps。
Phase (deg)给 through 路径加入固定相位偏置。默认 0°。
Reference Z (Ω)设置 Touchstone 参考阻抗。默认 50 Ω，必须为正数。
Through Paths用逗号输入要应用主插损曲线的路径，如 S21,S12。留空时使用相邻互易通道：1↔2、3↔4……；3 端口的第 3 端口不会被暗中当成分配器。
Overwrite Existing允许显式路径覆盖已有文件。默认关闭。自动命名路径即使关闭也会选择新编号。

4.1 Linear

Linear 在 Start 与 Stop 之间建立线性变化的正插损值，再按 through 路径生成完整网络。

参数功能默认值
Start Loss (dB)起始频率处的插损。0.2 dB
Stop Loss (dB)终止频率处的插损。20 dB

若配置的 through、反射和串扰合在完整矩阵中超过无源上限，Generate 会拒绝写文件。通常应增加 through 插损，或增大 Return Loss / Crosstalk 的 dB 数值。

4.2 Formula

Loss(f) = a · f + b · √f + c
参数功能默认值 / 注意事项
a / b / c公式的线性项、平方根项和常数项系数。0.08 / 0.6 / 0.1
Frequency Unit规定公式中 f 的数值单位。默认 GHz。改成 MHz 后同一频率的 f 数值变化，原系数不能原样沿用。

Formula 模式生成的仍是工程近似网络；公式名称不代表任何特定协议规范。输出前同样执行完整矩阵无源检查。

4.3 Draw

Draw 用页面内绘图区或文本控制点定义 through 路径的幅度曲线。绘图区采用常见 S 参数显示习惯：顶部 0 dB，插损曲线通常画为负 dB。

控件功能输入规则
Frequency : dB直接输入控制点；也会接收在绘图区点击产生的新点。示例：1GHz:-1, 20GHz:-8。至少 2 个点，频率必须位于 Sweep 内。
绘图区单击按点击位置追加一个频率:dB 控制点。先保证 Sweep 和 Draw Y Min/Max 有效；误点可在文本框中删除。
Draw Y Min / Draw Y Max控制绘图区纵轴范围。默认 −40 / 0 dB，最大值必须大于最小值。
Draw Fitsmooth 使用形状保持平滑曲线；linear 使用分段直线。两者都精确经过控制点；过近或近乎垂直的点会被拒绝。
Draw Domain选择在线性频率或对数频率坐标中进行插值。只影响拟合域，显示横轴仍为线性。

Generate 成功后，绘图区会切换成全部 Sij 的 Magnitude/Phase 曲线。再次编辑控制点、扫频范围或 Draw Y 轴会返回绘图区。

4.4 Modify

Modify 读取现有 Touchstone 文件，把指定路径在指定频率处调整到目标插损。目标值是正插损，例如 5GHz:3.0 表示该频点目标幅度为 −3 dB。

控件功能规则与反馈
Input File显示或直接输入源 .sNp 路径。改完路径后按 Enter 或移开焦点即可加载；成功后 Ports、Points、Start、Stop 和右侧预览都改为源文件数据。
Browse（Input）打开 Touchstone 文件选择器。支持选择 .s1p 至 .s8p；取消不清空原路径。
Targets (f:dB)设置一个或多个目标频率和正插损值。默认 5GHz:3.0,12GHz:8.0；目标必须在源文件范围内，不能互相过近。
Paths (Sij)指定需要修改的路径。默认 S21,S12；至少一个，端口下标不能超过源文件端口数。
Modify Curve Tension调节目标点之间形状保持 Hermite 曲线的局部斜率影响。默认 0.14，必须大于 0。它不绕过目标精确性或无源门禁。
Modify Domain在 log 或 linear 频率域中建立平滑修正。默认 log；仅改变频率方向的曲线形状。
Anchor Edges在源文件起止频率把修正量锚定为 0。默认开启，可减小修改对扫频边缘的影响。
Insert Targets若目标频率不在原网格中，将其插入输出网格。默认开启，使可行目标能够精确落在真实输出采样点。
当前 Modify 的无源处理：先验证源文件完整 S 矩阵；再用形状保持曲线修改所选路径。非目标频点若因平滑产生无源超限，程序会沿“原矩阵→候选矩阵”收缩修改量；目标频点保持精确。若目标本身不可能满足完整矩阵无源条件，程序明确拒绝，而不是悄悄改变目标。
看到 passive 拒绝时先读前缀。Input S-parameter matrix is not passive 表示源文件本身已经不满足采样点无源，换目标没有用；Requested target cannot satisfy sampled passivity 表示请求的目标与该频点其他矩阵元素组合后不可行，应提高该路径插损或调整相关通道；Modified…not passive 表示最终完整矩阵门禁未通过，文件不会写出。

Modify 成功会同时生成修改后的 .sNp 和 .sNp.report.txt。报告列出每条路径在每个目标频点的请求插损、修改前插损、最终达到插损和相位变化。

生成与 Modify 依据：默认值、按钮后端与输出规则；Modify 主流程；非目标频点无源收缩。

5 · PLOT

曲线区、Magnitude / Phase 与三个图表按钮

Generate 成功或 Modify 输入加载成功后，曲线区按矩阵顺序显示全部 Sij。所有子图共享易读的工程刻度；刻度显示不会改变文件中的频率或复数值。

按钮 / 操作功能鼠标行为
Magnitude显示每条 Sij 的幅度，单位 dB。只切换显示内容，不重新计算或写文件。
Phase显示每条 Sij 的相位，单位 degree。只切换显示内容。
⌗ 矩形缩放进入框选放大模式。在某一子图中按住左键拖出矩形；与平移模式互斥。
✥ 平移进入拖动曲线范围模式，默认选中。左键拖动；滚轮仍可围绕鼠标位置缩放。
⌂ 恢复范围所有子图恢复当前数据的推荐显示范围。不会改变数据或重新生成。

每个 Sij 子图保留自己的查看范围。切换 Magnitude / Phase 时会进入对应类型的查看状态；重新生成后查看范围会按新数据重置。

交互依据：曲线绘制、滚轮、平移、框选和复位逻辑。

6 · IMAGE TO S-PARAMETER

Image to S-Parameter 页签

本页的流程是“导入图片 → 核对坐标 → 提取 Trace → 配置输出网络 → 映射每个参数 → 检查采样与模型假设 → 复核并生成文件”。任何未分配通道都会在调用后端前被明确列出。

6.1 图片列表、预览、校准与 Digitize

控件功能可用条件 / 限制
Add一次选择一张或多张 PNG、JPEG、GIF 或 WebP。添加后自动尝试识别绘图区、坐标标签和参数名；信息齐全时自动 Digitize。最多 32 张；单张不超过 20 MB；总大小不超过 128 MB；相同文件内容去重。分析进行中暂不可再次添加。
Remove删除当前选中的图片；后续图片重新编号，引用该图片的映射变成 Unassigned。分析进行中禁用；没有图片时禁用。
Image 1 / Image 2…点击图片列表项切换当前图片、校准值、Trace 列表和预览。列表状态会显示 Required、Review、Detected 或可用 Trace 数量。
Preview 图片区域显示原图、检测到的绘图区框和提取 Trace 的高对比叠加线；点击可打开大图查看器。悬停或点击某个 Trace 行会突出对应叠加线。
Start / Stop / Step校准图片横轴频率范围和均匀采样步进。可输入 GHz/MHz/kHz/Hz；不带单位时按 GHz，例如 0 / 5 / 0.1 等同于 0GHz / 5GHz / 0.1GHz。Stop 大于 Start；输出点数 2–200000。修改后旧 Trace 失效，需要重新 Digitize。
X Scale选择图片横轴为 Linear 或 Log。Log 必须从正频率开始。Step 仍用于建立输出采样数量。
Y Max / Y Min (dB)校准图片纵轴的顶部和底部幅度。Y Max 必须大于 Y Min。
Digitize / Re-digitize按当前坐标重新定位连续彩色轨迹并提取幅度样点；完成后显示 Trace 1、Trace 2……只有 Start、Stop、Step、Y Max、Y Min 全部填写后可用。重新识别会清除旧曲线映射，避免使用过期数据。
Trace 行点击可持续高亮这条曲线；鼠标悬停可临时高亮。橙色虚线标出需要对照原图的局部区段，并说明像素证据的复核状态。该提示不是经过标定的识别准确率。橙色区段可能来自插值、共享像素、原图缺口、尖锐转折、路径与源像素不符或短促的异常上跳；它表示“请人工确认”，不等于程序已经证明曲线错误。这里仅显示曲线身份、颜色、样点质量和“已被哪个输出使用”；所有 S 参数映射统一在右侧网络面板选择，避免左右两套下拉框互相覆盖。
Edit traces框选绘图区、排除图例、从原图取色、添加或删除目标线，并用锚点引导局部追踪。编辑器支持 200% / 300% 放大和撤销。先核对主界面的坐标轴。Apply and retrace 后重新检查曲线并映射；失败会保留原数据。
Undo correction / Save recipe / Magnitude CSV撤销已应用修正；保存与源图哈希绑定的 JSON 方案；导出含来源信息的幅度样点。修正或撤销会使旧映射确认失效；恢复方案必须匹配同一图片。
OCR 是辅助，不是裁决。Tesseract 未安装或图片文字不清时，曲线路径仍可能可提取，但频率、Y 轴和参数标签需要人工填写或确认。程序不会用与图片无关的默认值悄悄补全“识别成功”。
局部风险提示也是辅助判据。程序会在整条曲线统计之外检查短区段，并把可疑位置直接叠加在原图上；没有橙色标记只代表当前规则未发现风险，不代表图片一定无歧义。导出前仍应检查关键频段和 Trace 身份。

6.2 Output Networks、频率策略和 S 参数映射

控件功能规则
Output Networks 数量设置本次工作区要配置的输出网络数量。1–6。减少数量会删除尾部网络的本次会话配置。
Output 1 / Output 2…点击网络列表项切换右侧当前网络。初始 Output 1 为 4 端口 Sij；新增网络初始为 2 端口。
Parameter SetSij 使用单端参数；Mixed-mode 使用 SDD/SDC/SCD/SCC 映射。Mixed-mode 只允许 2、4、6、8 个物理端口。切换参数集会重建映射。
Ports设置当前输出网络的物理端口数。单端可选 2、3、4、6、8；混合模必须是偶数端口。
Output File显示自动输出文件名，如 output_1.s4p。只读，写入默认输出目录；同名存在时自动编号，不覆盖。
Reciprocal开启后，一个参数的来源同步到其转置参数，例如 S21 与 S12。默认开启。关闭后可分别选择两个方向。
Frequency Range: Common Range使用全部已映射图片曲线的共同覆盖区间。安全默认；图片没有交集时明确拒绝。只用默认曲线时无法推导网格，必须改为 Manual。
Frequency Range: Manual用 Start、Stop、Step 明确规定一个均匀输出网格。Step 必须精确整除 Start–Stop 范围，点数不超过 200000。
Frequency Range: Full Range使用全部映射图片的并集范围。超出某张图覆盖区时必须明确勾选 Fill Missing Range。
Fill Missing Range在图片曲线覆盖外用默认幅度补齐：反射 −20 dB，其他通道 −80 dB。Common Range 不显示；Manual / Full Range 需要越界时才应开启。状态栏会标明 Default fill。
Coverage Status / Use finer step显示输出网格和覆盖范围。若当前步进改变了已识别的局部细节，列出差异，并在有合法建议时提供更细步进。只有点击后才采用建议；输出仍为统一网格，并需重新复核。提示比较的是提取数据与输出采样，不是仪器精度。
Phase and impedance assumptions明确选择零相位或固定延迟假设，并设置参考阻抗。幅度图片不能恢复厂商测量相位；此处是输出模型假设。
每个 S 参数的映射下拉框为当前网络每个参数选择某条图片 Trace，或选择 Return loss −20 dB / Crosstalk −80 dB。Unassigned、Unknown 和 Formula 都不是可生成来源；Generate File 会列出所有未分配参数。
Open Folder打开图片页最近一次成功生成文件所在目录。与生成页的 Open Folder 分别记录最近输出；图片页尚未成功生成时拒绝。
Generate File统一输出频率网格，插值已映射曲线，补齐默认通道，建立完整矩阵，显示当前来源、采样差异与模型假设，经复核确认后执行采样点无源检查并写 Touchstone。未分配、频率冲突、超出覆盖但未授权填充、点数超限或完整矩阵非无源时不会写文件。
关于 Formula 映射：图片页下拉列表中的 Formula 是保留来源标记，当前版本没有为它提供可执行曲线。选择后该通道仍被视为 Unassigned；请改选真实 Trace、Return loss −20 dB 或 Crosstalk −80 dB。

不同图片原始样点数可以不同。程序把已选择曲线插值到一个共同、均匀且包含两端点的输出网格，并报告哪些通道被重采样；这不等同于增加原图测量分辨率。

Mixed-mode 配置会先按完整 SDD/SDC/SCD/SCC 映射建立零度相位复矩阵，再转换为物理单端端口后写入 .sNp。单张幅度图不会被直接改名成单端 Sij。

9 · RECIPES

四条常用操作流程

修改现有 S2P 的 S21 / S12

  1. 进入 Generate and Modify S-Parameter → Modify。
  2. 点击 Browse 选择源文件，确认状态显示端口数、点数和频率范围，右侧出现源曲线。
  3. Targets 输入正插损目标，例如 5GHz:3.0,12GHz:8.0；Paths 输入 S21,S12。
  4. 建议保留 Anchor Edges 和 Insert Targets；输出路径留空可避免覆盖源文件。
  5. 点击 Generate。成功后查看 Magnitude / Phase，再打开 .report.txt核对实际达到值。

手绘一条插损曲线

  1. 进入 Draw，设置 Sweep 和 Draw Y Min/Max。
  2. 在图中至少单击两次，或直接输入 1GHz:-1, 10GHz:-4, 20GHz:-8。
  3. 选择 smooth / linear 和 linear / log 拟合域，点击 Generate。

从一张曲线图片生成 S2P

  1. 进入 Image to S-Parameter，点击 Add。
  2. 核对 Start、Stop、Step、Y Max、Y Min；有空值时人工填写，然后点 Digitize。
  3. 检查原图叠加线；漏线、错线时用 Edit traces 修正。把 Ports 设为 2，按需要保留 Reciprocal。
  4. 在 S11/S12/S21/S22 映射中选择真实 Trace 或明确的 −20/−80 dB 默认曲线。
  5. 选择 Common Range；Coverage Status 显示网格且无 Unassigned 后，点击 Generate File，核对频段、采样损失和模型假设，勾选复核后确认生成。

组合不同频率网格的多张图片

  1. 逐张核对并 Digitize，每张图片保留自己的校准。
  2. 把各 Trace 映射到所需参数。优先使用 Common Range。
  3. 确实需要并集范围时改为 Full Range，并明确判断默认补齐是否符合用途后再勾 Fill Missing Range。
  4. 检查 Coverage Status 的 resampled channels、Default fill 和总点数。
10 · TROUBLESHOOTING

常见拒绝原因与正确处理

提示或现象真正含义处理方法
Input S-parameter matrix is not passiveModify 源文件在某个现有采样点的完整矩阵最大奇异值超过 1。检查源文件、端口顺序和参考阻抗；用可信的无源化/矢量拟合流程修复源模型，或选择经验证的源文件。仅更换 Paths 或目标频点不能修复源矩阵。
Requested target cannot satisfy sampled passivity目标频点本身要求的某条路径太强，与同频点其他 S 参数组合后不可能保持完整矩阵无源。提高目标插损值（让幅度更小），减少同时增强的路径，或重新审视反射、串扰和互易路径设定。程序不会悄悄放宽目标。
Generated / Modified matrix is not passive当前生成配置的完整矩阵超出采样点无源上限。增加 through 插损；增大 Return Loss 和 Crosstalk 的 dB 数值；避免把多条大幅度路径同时接入同一端口。
Target frequencies must be inside…Modify 目标超出源文件 Start–Stop。把目标移入范围；不要用外推伪造源文件未覆盖的频率。
Target frequencies are too close…目标彼此或与扫频边缘过近，无法可靠建立平滑修正。拉开目标频率，或先增加源文件频率分辨率。
Output file already exists使用了明确路径且 Overwrite Existing 未勾选。改文件名、勾选覆盖，或清空 Output File 使用自动编号。
Draw mode requires at least two control pointsDraw 控制点不足。在绘图区至少点击两次，或输入至少两组 frequency:dB。
Unassigned channels…图片页仍有映射为 Unassigned、Unknown 或 Formula。逐项选择某条已识别 Trace、Return loss −20 dB 或 Crosstalk −80 dB。
Frequency ranges do not overlapCommon Range 下各映射图片没有共同覆盖区。校正错误坐标；或改用 Manual / Full Range，并明确评估 Fill Missing Range。
Manual step must divide… exactly手动 Step 不能构成包含 Start 和 Stop 的均匀网格。选择能整除跨度的 Step。
Review / OCR 不完整图片坐标或参数文字没有被可靠识别。人工填写全部坐标并 Re-digitize，再在右侧网络面板选择各 S 参数对应的 Trace。需要自动文字识别时安装 Tesseract 并加入 PATH。
Open Folder 提示尚未生成对应页签在本次程序启动中还没有成功输出。先在该页完成一次成功生成；两个页签分别保存最近输出。
怎样让 Modify 更容易成功？

先确认源文件本身采样点无源；目标用正插损值，不要把 −3 dB 写成 -3。优先保留 Insert Targets 和 Anchor Edges，目标不要挤在一起。若目标点报告不可行，应提高目标插损或减少同一端口上的强耦合路径，而不是反复修改 Curve Tension 期待绕过完整矩阵无源条件。

为什么只看 S21 小于 0 dB 仍可能被拒绝？

无源判定针对同一频率的完整 S 矩阵。即使每个单项都不超过 0 dB，多条反射、through 和串扰同时存在时，矩阵最大奇异值仍可能大于 1，代表某个端口激励组合会产生超过输入的总功率。

能否把图片页生成的文件当成原厂 S 参数？

不能。它是按图片可见幅度、人工/自动校准、零度相位和所选默认通道组成的工程近似。原厂相位、未显示矩阵块、参考阻抗归一化和测量不确定度都无法由幅度截图恢复。

Windows all-in-one 单文件版

正式 Windows 发布包解压后只有一个 InsertionLossTool.exe，没有 _internal，接收者不需要安装 Python。双击 EXE 即可启动。

项目说明
系统64 位 Windows 10/11。
WebView2必须安装 Microsoft Edge WebView2 Runtime；Windows 11 通常随系统提供，但缺失时程序无法显示主界面。
Tesseract图片文字自动识别的可选外部依赖，不打包进 EXE。缺少它时仍可人工校准和提取曲线。
首次启动单文件 EXE 会先解包到系统临时目录，因此启动可能比目录版慢；退出后由引导程序清理临时目录。这不会在发布目录产生 _internal。该行为见 PyInstaller 官方 one-file 运行说明。
SmartScreen当前构建没有商业代码签名，Windows 可能显示信誉提示。应核对发布来源和 SHA-256，不应关闭系统安全功能或下载来历不明的副本。
自动构建不替代实机人工验收。公开仓库 workflow 会在 Windows runner 上执行完整测试、压力测试、源码与 EXE 自检、WebView2 渲染探针和单 EXE ZIP 结构检查；真实用户电脑的双击、SmartScreen、文件选择器和完整交互仍应单独记录。

12 · GLOSSARY

术语表

术语本工具中的含义
Insertion Loss本工具输入为正 dB 损耗；曲线幅度通常显示为对应的负 dB。
Sij从输入端口 j 到输出端口 i 的单端散射参数。
Through Paths应用主要插损曲线的传输路径；其余非对角项使用串扰底。
Reciprocal互易网络映射联动；例如选择 S21 来源时同步设置 S12。
SDD / SDC / SCD / SCC混合模输出模式与输入模式组合。按 Keysight 记法，输出模式写在输入模式之前。
Sampled-passive每个离散频点的完整 S 矩阵最大奇异值不超过 1（带数值容差）。
σmax全部输出频点中最坏的最大奇异值；越接近 1，无源余量越小。
Anchor Edges把 Modify 修正量在扫频两端锚定为 0。
Insert Targets把 Modify 目标频率插入实际输出网格，以便可行目标精确落点。
Common / Full Range多张图片覆盖范围的交集 / 并集。
Default fill在图片未覆盖范围用 −20 dB 反射或 −80 dB 其他通道补齐。
