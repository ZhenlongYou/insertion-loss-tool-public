# Insertion Loss Tool 中文使用说明书

本目录保存与当前 Insertion Loss Tool 桌面界面对应的中文 HTML 使用说明书。

打开方法：

1. 下载本目录中的 `InsertionLossTool_使用说明书.html`。
2. 使用 Edge、Chrome、Firefox 或 Safari 双击打开。
3. 说明书是单个自包含 HTML，不依赖图片目录或网络样式文件；左侧支持全文搜索，也可使用“打印 / PDF”。

说明书覆盖：

- `Generate and Modify S-Parameter` 与 `Image to S-Parameter` 两个主页签；
- Linear、Formula、Draw、Modify 四种模式；
- 每个按钮、输入项、复选框、下拉框和动态列表；
- 输出文件、频率网格、图片映射和 Windows 单文件版；
- Modify 的 sampled-passivity 拒绝原因与处理方法。

功能说明按独立 public 仓库的当前 `main` 快照核对。界面或算法更新后，应同步更新说明书的功能快照和控件清单。
