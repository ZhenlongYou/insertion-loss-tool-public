# Touchstone 插损工具算法原理说明书

## 1. 量的定义

S 参数描述端口入射波与出射波的复数比。对从端口 1 到端口 2 的传输：

\[
S_{21}(f)=\frac{b_2(f)}{a_1(f)}.
\]

电压波的插入损耗通常定义为

\[
IL_{21}(f)=-20\log_{10}|S_{21}(f)|\ \mathrm{dB}.
\]

若讨论功率比，则是 (-10\log_{10}|S_{21}|^2)，数值相同但物理解释不同。工具生成、
修改和绘制的是复 S 参数曲线，而不是只生成一列 dB 数。

## 2. 曲线生成模型

线性模式先生成非负损耗 (L(f))，再转为幅度

\[
|S_{21}(f)|=10^{-L(f)/20}.
\]

协议公式模式使用

\[
L(f)=af+b\sqrt f+c,
\]

其中 \(f\) 必须先换成声明的 GHz 或 Hz，因此系数带有与所选频率单位相关的量纲。若有
纯延迟 \(\tau\)，复响应为

\[
S_{21}(f)=|S_{21}(f)|e^{-j2\pi f\tau}.
\]

这说明同样的幅频曲线可以有不同相位；仅凭插损不能推断时域脉冲形状。

## 3. Touchstone 与端口语义

文件可用 RI、MA 或 DB 表示复数：

\[
RI=\Re S+j\Im S,\quad MA=(|S|,\angle S),\quad DB=(20\log_{10}|S|,\angle S).
\]

S2P 每个频点有 (S_{11},S_{21},S_{12},S_{22})；S4P 有 16 个元素。端口映射必须先
声明，不能把“第二列”泛化成 S21。默认 reciprocal 通道会设置 (S_{12}=S_{21})，
但真实无源网络可能非互易，导入文件时必须保留原值。

## 4. 多图片频率合成与混合模

每条数字化曲线先保留自己的严格递增原始频率数组 \(f_i\)和原始观测点数。
这一层只表示图片提供了多少可识别信息；不同图片、不同颜色曲线的原始点数可以不同。

组合一个输出网络时，所有已映射图片曲线和默认通道共用唯一主频率网格
\(f_\mathrm{out}\)。自动模式
取所有已映射曲线覆盖范围的交集

\[
f_\mathrm{start}=\max_i f_{i,0},\qquad
f_\mathrm{stop}=\min_i f_{i,-1},
\]

令每条源曲线的典型间隔为 \(\tilde{\Delta f_i}=\mathrm{median}(\Delta f_i)\)，
自动安全步进不细于最粗的有效源分辨率：

\[
\Delta f_\mathrm{safe}=\max_i\tilde{\Delta f_i},\quad
N=\max\!\left(1,\left\lfloor\frac{f_\mathrm{stop}-f_\mathrm{start}}
{\Delta f_\mathrm{safe}}\right\rfloor\right),\quad
f_\mathrm{out}=\mathrm{linspace}(f_\mathrm{start},f_\mathrm{stop},N+1).
\]

这样起点、终点都被保留，中间步进严格相等，且不会在末尾追加一个不等间隔点。
手动模式必须满足

\[
\frac{f_\mathrm{stop}-f_\mathrm{start}}{\Delta f_\mathrm{manual}}\in\mathbb{N},
\]

否则直接报错。仅使用默认反射或耦合曲线时没有图片可用于推断频率轴，因此
也必须手动给出起始、终止和步进。

图片幅度在 dB 域分段线性插值到 \(f_\mathrm{out}\)；默认通道则直接在
\(f_\mathrm{out}\) 上生成常数。最终每个 S 参数的起点、终点、步进、点数和逐点
频率值完全相同。超出原曲线范围默认拒绝，`全部范围` 只有明确选择默认补齐
才可继续。重采样会增加数值表中的点，但不代表图片的实际分辨率提高。

混合模参数按输出模式、输入模式排列为 SDD、SDC、SCD、SCC。例如 SCD 表示差模输入、
共模输出；该命名顺序可核对 Keysight FlexDCA 的
[Balanced Devices](https://helpfiles.keysight.com/scopes/FlexDCA-UG/Content/Topics/TDR-TDT-Mode/Parameters/a_ST_parameters.htm)。
在端口成对、每根导体参考阻抗相等、差模参考阻抗为 \(2Z_0\)、共模参考阻抗为
\(Z_0/2\) 的实现约定下，按照显式正负端口对的顺序构造从物理端口到
\([D_1\ldots D_n,C_1\ldots C_n]\) 的正交变换 \(T\)，则

\[
S_\mathrm{mm}=T S_\mathrm{se}T^\mathsf{T},\qquad
S_\mathrm{se}=T^\mathsf{T}S_\mathrm{mm}T.
\]

只有同一频点上的完整复数混合模矩阵、无重复且覆盖全部物理端口的二元端口配对、
以及参考阻抗都已知时，逆变换才开放。非相邻配对会据用户给定顺序生成对应置换，
不会套用默认的 \((1,2),(3,4),\ldots\) 变换。
单独 SDD/SDC 曲线或只有 dB 图片时方程不足，必须保持混合模。规范依据为 IBIS Open
Forum [Touchstone File Format Specification 2.0](https://ibis.org/touchstone_ver2.0/touchstone_ver2_0.pdf)：
混合模定义与参考阻抗条件见印刷页 19–20，`[Mixed-Mode Order]` 见页 20–22，多端口矩阵
互换见 Appendix A 页 28–32。

## 5. 平滑修改的数学意义

给定目标点 \((f_i,L_i)\)，先计算相对原曲线的控制修正量
\(\Delta L_i=L_i-L_\mathrm{old}(f_i)\)。工具用形状保持三次 Hermite/PCHIP
曲线插值 \(\Delta L(f)\)：局部极值处斜率置零、同向区间使用受限斜率，并把每段结果
裁剪到相邻控制修正量之间。因此曲线精确经过目标点，但不会像无约束 Gaussian RBF
那样在控制点之间产生正负过冲。随后令

\[
|S'_{21}(f)|=10^{-[L_\mathrm{old}(f)+\Delta L(f)]/20}.
\]

修改相位时保留原始 \(\phi(f)\)：

\[
S'_{21}(f)=|S'_{21}(f)|e^{j\phi_\mathrm{old}(f)}.
\]

缺少目标频点时，工具在 dB 域插值幅度、对相位先展开再插值，并把控制频点插入输出
网格，避免目标只存在于报告而不存在于实际文件。若新插入的完整矩阵越过无源边界，
所有 S 参数在该新频点统一除以 \(\sigma_\max\)；这是正实数缩放，不改变相位或端口间
比例。过近控制点、频率超出原扫频范围或隐含极陡斜率时拒绝。

## 6. 无源性与物理边界

对于参考阻抗相同的无源多端口，散射矩阵应满足最大奇异值

\[
\sigma_{\max}(S(f))\le1.
\]

对 2 端口，常见必要条件包括 (|S_{11}|^2+|S_{21}|^2\le1) 和对应的另一列条件。
Modify 在重采样前先检查输入矩阵，避免把源文件已有的非无源问题归因于目标点。候选
曲线在非目标频点若越过边界，就在原矩阵 \(S_0\) 与候选矩阵 \(S_1\) 的线段
\(S(\lambda)=S_0+\lambda(S_1-S_0)\) 上二分寻找最大可行 \(\lambda\)。谱范数单位球是
凸集，所以从无源的 \(S_0\) 出发，这个收缩不会跨越其他不可行区间。精确目标点不参与
收缩：目标本身可行就原值保留，目标本身不可行则明确报告频率和最大奇异值。

工具在写出前检查一次完整矩阵，打包版自检还会重新读取最终 Touchstone 文件后再次检查，
避免“生成过程通过、落盘结果却非无源”的假绿。这仍只是采样点检查，而非充分的因果性
证明；频率轴太窄、相位不连续、任意手绘曲线仍可能不能
由有限 Touchstone 点实现为稳定时域网络。

当前重采样对 wrapped 相位采用最小跳变展开，条件性地假设相邻频点的真实相位变化小于
\(\pi\)。若外部只能保证 \(|\tau|\le\tau_{\max}\)，可辨识的充分条件为

\[
2\pi\tau_{\max}\max_i(f_{i+1}-f_i)<\pi.
\]

当前接口尚未接收并验证这个物理先验；80 ps 纯时延在 10 GHz 步进下可与 -20 ps 别名
产生相同 wrapped 样本。因此普通展开只在调用者已知频率采样足够密时有条件合理；没有
更密数据、粗时延或时域证据时，不能把有限插值结果称为唯一相位恢复。

## 7. 手算例子

若 (L=6\) dB，则 (|S_{21}|=10^{-6/20}=0.5012)。若纯延迟 80 ps、频率 5 GHz，
相位为 (-2\pi\cdot5\times10^9\cdot80\times10^{-12}=-0.8\pi\) rad，即约 -144°。
若把 6 dB 错当作 (-10\log_{10}|S|)，会得到错误的幅度 (0.25)，相差一倍。

## 8. 结论与剩余风险

生成/修改/解析方向合理；当前输出应称为“曲线模型”或“工程网络近似”。不能仅凭一条
插损曲线声称真实连接器、封装或协议通道的合规性。必须继续用独立 Touchstone 解析、
RI/MA/DB 往返、端口映射、无源性和相位连续性测试验证。源码追踪：
`src/insertion_loss_tool/models.py` 与 `src/insertion_loss_tool/datasheet.py`。
